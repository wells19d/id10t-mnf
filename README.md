# ID10T: MNF (id10t-mnf)

Project ID10T: A Memory Not Found

### Python / Flask Final Project

- This is going to serve as my "self" final project in learning the basics of Python.
- We are going to take Python, using Flask, to build a "Zork" style html / css terminal based game.

---

### Concept

- Terminal based game
- User given commands as actions
- Terminal styled, DOS like, into html
  - Will allow anyone to play anywhere
  - No graphical base to increase backend focus

---

### Idea

- "Zork" like game simulated on a terminal for based actions.
- Simplified intro story, User has no memory, lost in the forest.
- Help section for list of approved interactions
  - Primary:
    - GO `<direction>`
    - TAKE `<item>`
    - USE `<item>`
  - Secondary (combined with primary):
    - ON `<target>`
    - WITH `<target> or <item>`
